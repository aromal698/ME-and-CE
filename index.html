Start your AI Study Hub

This page is the start guide. The working app runs with Python and Streamlit; opening this HTML file alone does not start the AI.

  1. Install Ollama for Windows and open it.
  2. In this folder, double-click Run_Pathway.bat. It installs the app packages and starts the study hub in your browser.
  3. Open AI Study Assistant. If Ollama is running without a model, click Download free AI model now. Then paste or upload the official KTU syllabus and generate notes, exam micro bits, practice questions, or explanations.
The free AI runs locally through Ollama. The first model download needs internet and disk space. KTU portal updates are official links; paste or upload a notice for the AI to summarize it.

If a startup error appears, keep the terminal window open and share the exact error text so it can be diagnosed.

Pathway Engineering Study Hub

This is the start guide. The working app runs with Python and Streamlit; opening this HTML file alone does not start the AI.

  1. Double-click Run_Pathway.bat. It installs the app packages and opens the study hub in your browser.
  2. Choose an AI in the left sidebar. For Gemini, create a key at Google AI Studio and paste it into the masked Secret API key field.
  3. For local AI, install and open Ollama for Windows, select Ollama (local), then use Add Free AI to download the model.
  4. Open AI Study Assistant, choose a semester subject, paste or upload the official KTU syllabus, and generate notes, exam micro bits, practice questions, or explanations.
Ollama processes prompts on your computer. Gemini sends submitted prompts and syllabus text to Google; API quota or billing depends on your account. KTU portal updates are official links; paste or upload a notice for the selected AI to summarize.

If a startup error appears, keep the terminal window open and share the exact error text so it can be diagnosed.
